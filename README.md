## 功能特性

1. **三关解题助手：** 结果窗口内置校准 / 西蒙 / 解密三个页签，默认快捷键 `Alt + X`（校准）、`Alt + C`（西蒙）、`Alt + V`（解密），均可自行修改。

2. **校准（第一关 · 波形）：** 自动识别波形面板，给出振幅 / 频率 / 相位 / 偏移四个滑块答案，并绘制与游戏内目标完全一致的橙色双正弦校准曲线供比对。

3. **西蒙（第二关 · 记忆序列）：** 全自动模式——自动检测「开始 / 正在播放 / 复现」状态，自动录制每轮亮起序列并轮次推进，你只需要照着推荐按；也保留手动录制的自由模式。

4. **解密（第三关 · 四位符文）：** `Alt + V` 自动识别盘面符文与反馈色（红 / 黄 / 绿），采用「候选优先、搏直接命中」的 minimax 策略，保证 4 次提交内破解；支持自学习词库纠正识别误差。

5. **全局裁切模式：** 结果窗口头部四角方框按钮开关。框选一次后所有截图管线只处理该区域（自动归一化到 1920 等比宽度），屏幕上常驻橙色指示框；指示框对截屏隐身，不污染识别管线。

6. **离线识别：** 全部识别基于 Windows 系统内置 OCR 与像素几何分析，零模型下载、零网络请求，单文件 exe 即装即用。

7. **滤镜免疫：** 反馈色与波形定位均采用相对色序 / 相对亮度判定，不依赖绝对 RGB 阈值，英伟达动态亮丽、游戏内增亮等滤镜引起的颜色漂移不影响识别。

8. **不抢焦点结果窗口：** 结果窗口始终置顶且不夺取游戏焦点（WS_EX_NOACTIVATE），且对截屏隐身（WDA_EXCLUDEFROMCAPTURE）；支持鼠标点击直接复制。

9. **界面多语言：** 内置简体中文与 English 两套界面（含托盘菜单与符文名），可在设置页切换。

## 工作流程

```
热键（Alt+X / Alt+C / Alt+V）触发
    ↓
截屏（全局裁切模式下仅取框选区域，归一化到 1920 等比宽度）
    ↓
按关卡走对应识别管线：
  · 校准：波形面板定位 → 结构化参数求解 → 滑块答案 + 校准曲线
  · 西蒙：状态区快检（开始/播放/复现）→ 亮起格采集 → 步骤列表同步
  · 解密：定位 4 个符文框 → 识别符文与反馈色 → minimax 推荐下一步
    ↓
置顶不抢焦点结果窗口展示答案，点击复制
```

## 使用方法

1. 运行 exe，程序驻留系统托盘，托盘菜单可打开结果窗口 / 设置页
2. 建议先开启**全局裁切模式**（结果窗口头部四角方框按钮）：拖框选中解题面板区域，之后所有识别只看这块区域，抗干扰能力最强
3. 进入对应关卡后按快捷键：
   - `Alt + X` 校准页：展示四个滑块答案与校准曲线，照抄即可
   - `Alt + C` 西蒙页：自动模式全程托管，底部状态区显示当前轮次与录制到的步骤序列
   - `Alt + V` 解密页：自动识别四个符文与反馈色，展示推荐提交，点击复制；识别失败时红字提示原因，不再跳转页签
4. 识别不准时在结果窗口逐项修正后重算；解密页提供自学习词库（添加 / 更新 / 删除词条）持续提升识别准确率

> 系统要求：Windows 10 2004 及以上；OCR 依赖系统内置中文语言包（zh-CN，中文版 Windows 默认自带）。

## 技术实现

- **识别管线**（`src-tauri/src/`）：
  - `wave.rs` — 波形结构优先分级定位（暗阈值 30→45→60 递进 + R²≥0.5 校验兜底），完整双正弦参数反推
  - `simon.rs` — 状态区相位机（待机 / 播放 / 复现）纯像素快判 + 亮起格独立采集线程，播放期零 OCR 开销；1 帧暗即清除 + 300ms 不应期支持同格连亮
  - `runes.rs` — 符文框定位（纵向带低水位桥接）→ 边框相对色序判色 → 模板匹配 + OCR 兜底识别单字
  - `solver.rs` — 解密 1296 候选的候选优先 minimax 算法，首猜固定「空火水风」，4 次内必解
- **全局裁切模式**（`window.rs` / `cmd.rs`）：框选坐标支持负全局坐标（副屏），重启可恢复；热键未开裁切时先拉框选窗、完成后自动派发操作；所有常驻窗口对截屏隐身
- **推荐引擎**（`src/utils/runes.js` + Web Worker）：本地离线计算下一步提交
- **多语言**（`src/i18n/`）：i18next 实现，zh_CN / en_US 两套语言包，Rust 侧只返回错误码、译文由前端按语言渲染
- **三架构构建**：x64（x86_64-pc-windows-gnu）、x86 / ARM64（llvm-mingw gnullvm），产物均通过 PE 头与文件版本校验；WebView2Loader 已静态嵌入，均为真正的单文件

## 从源码构建

```bash
pnpm install
pnpm tauri build
```

> **注意路径**：源码与 `CARGO_TARGET_DIR` 所在路径必须为纯 ASCII 字符。路径含中文时（如本机 E 盘目录），cargo 会将路径规范化回真实中文路径，导致链接器 ld.exe 找不到 rlib 而构建失败——建议把仓库放在纯 ASCII 路径，或通过 `CARGO_TARGET_DIR` 把构建产物指到 ASCII 路径。

## 常见问题

<details>
<summary><b>按快捷键没有反应？</b></summary>

确认程序在托盘运行中；确认游戏为无边框窗口化（非独占全屏），独占全屏下置顶窗口不可见。若从未开启全局裁切模式，热键会先弹出框选窗让你框选解题区域，框选完成后自动执行对应识别。
</details>

<details>
<summary><b>识别失败 / 提示红字？</b></summary>

失败原因会直接显示在当前页下方红字（如「截图失败」「未找到符文框」）。优先检查全局裁切模式的框选区域是否覆盖完整解题面板；高分辨率 / 4K 下游戏内界面缩放调大可显著提升识别率。
</details>

<details>
<summary><b>开滤镜后识别不准？</b></summary>

识别采用相对色序 / 相对亮度判定，已适配英伟达动态亮丽、游戏内增亮等亮度类滤镜；若使用强色调滤镜（如夜视模式）仍异常，可提交 issue 附全屏截图。
</details>

<details>
<summary><b>窗口拖到另一个屏幕不见了？</b></summary>

窗口拖动不允许跨屏幕，仅允许在快捷键呼出时所在的屏幕内移动；如需在另一屏幕使用，请关闭窗口后在该屏幕重新按快捷键呼出。
</details>

## 更新日志

### v1.1.0 · 三关解题助手 + 全局裁切模式

自 v1.0.4 之后的全部改动合并为本版本：

1. **新增校准 / 西蒙 / 解密三关助手：** 结果窗口改为三页签结构，`Alt + X` / `Alt + C` / `Alt + V` 分别触发对应关卡的自动识别与求解，所有关卡功能集成进同一结果窗口
2. **西蒙全自动模式：** 状态机驱动（待机 / 播放 / 复现），自动检测开始按钮、自动录制每轮亮起序列并按轮次推进，播放期零 OCR 开销；支持同格连亮、窗外污染防御、3+X 轮次截断
3. **解密策略升级：** 核心算法替换为用户提供的 minimax 版本（候选优先、搏直接命中），弃用探针步，首猜固定「空火水风」，保证 4 次内必解
4. **全局裁切模式：** 框选一次后所有截图管线仅处理框选区域并归一化到 1920 等比宽度；橙色指示框对截屏隐身（WDA_EXCLUDEFROMCAPTURE）；热键在未开裁切时自动先拉框选窗
5. **界面多语言：** 内置简体中文与 English 两套界面（含托盘菜单与符文名），删除其余 17 个语言包；符文识别失败提示按错误码本地化
6. **一批稳定性修复：** 西蒙同格连亮（1 帧暗即清除 + 300ms 不应期）、分关卡录制目标、截图 IO 串行锁、simon_step 代际守卫全量同步、AFTER_CROP 原子化、波形窗口可见性 Win32 判定、失败不再跳转页签等
