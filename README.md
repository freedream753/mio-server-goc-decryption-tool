## 功能特性

1. **全自动符文识别：** `Alt + C` 一键全屏截图，自动定位游戏面板上「当前猜测」的 4 个符文框，识别符文（空 / 火 / 水 / 风 / 土 / 雷）与反馈色（红 / 黄 / 绿），自动写入本局历史，无需手动录入。

2. **离线识别：** 符文定位、边框取色与字符识别全部在本地完成，零模型下载、零网络请求，单文件 exe 即装即用。

3. **滤镜免疫：** 反馈色按符文方框边框的相对色序判定，不依赖绝对 RGB 阈值，英伟达动态亮丽 / 游戏内增亮等滤镜引起的整体颜色漂移不影响识别。

4. **不抢焦点结果窗口：** 结果窗口始终置顶且不夺取游戏焦点（WS_EX_NOACTIVATE），直接给出识别结果与下一步推荐提交，点击即可复制，不打断游戏按键操作。

5. **逐项纠正：** 识别不准时可在结果窗口逐个修正符文与颜色后重算，并提供「撤回本次」「新一局」兜底。

6. **手动助手与框选兜底：** 托盘 / 设置侧栏的「四位符文解密」窗口保留，用于切换判色规则、手动录入历史与中途接入；结果窗口的框选按钮可在自动定位失败时手动框选屏幕区域识别。

## 工作流程

```
Alt + C 全屏截图
    ↓
定位「当前猜测」的 4 个符文框（面板亮度 / 边框几何）
    ↓
识别 4 个符文（空 / 火 / 水 / 风 / 土 / 雷）+ 4 个反馈色（红 / 黄 / 绿）
    ↓
与本局历史去重后自动追加一条记录（localStorage，键 goc-rune-session-v1）
    ↓
置顶不抢焦点结果窗口：识别结果 + 下一步推荐提交，可一键复制
```

## 使用方法

1. 运行 exe，程序驻留系统托盘
2. 打开 GOC 奇术终端符文页面，新一局按推荐先提交「空、火、水、风」
3. 游戏返回反馈后按 `Alt + C`：自动识别盘面上的 4 个符文与其反馈色，并写入本局历史
4. 结果窗口展示识别结果与下一步推荐提交，点击推荐即复制；全部绿色时提示本局成功
5. 10 秒倒计时结束自动隐藏（点击复制 / 拖动窗口会重置倒计时，拖动期间倒计时冻结）
6. 识别不准时在结果窗口逐项纠正符文与颜色后重算，或用「撤回本次」回退；判色规则与手动录入走「四位符文解密」窗口

> 系统要求：Windows 10 及以上；字符识别依赖系统内置中文 OCR 语言包（zh-CN，中文语言模式的 Windows 默认自带）。

## 技术实现

- **符文识别管线**（`src-tauri/src/`）：全屏截图 → 定位 4 个符文框 → 符文方框边框取色判定反馈色 → 符文单字识别；任一位置识别失败则留空，交由结果窗口人工纠正
- **推荐算法**（`src/utils/runes.js` + Web Worker）：1296 个候选答案按判色规则（存在即黄 / 按数量匹配）筛选，给出可保证 4 次内破解的下一步提交
- **本局历史**（`src/utils/rune-session.js`）：localStorage 键 `goc-rune-session-v1`，快捷键自动识别与手动助手共用同一份历史
- **结果窗口**（`src-tauri/src/window.rs`）：Tauri v1 + windows-rs 补充 Win32 调用实现 WS_EX_NOACTIVATE / SW_SHOWNA，拖动窗口期间倒计时冻结
- **三架构构建**：x64（x86_64-pc-windows-gnu）、x86 / ARM64（llvm-mingw gnullvm），产物均通过 PE 头与 DLL 依赖表校验（仅系统库）

## 从源码构建

```bash
pnpm install
pnpm tauri build
```

> **注意路径**：源码与 `CARGO_TARGET_DIR` 所在路径必须为纯 ASCII 字符。路径含中文时（如本机 E 盘目录），cargo 会将路径规范化回真实中文路径，导致链接器 ld.exe 找不到 rlib 而构建失败——建议把仓库放在纯 ASCII 路径，或复制一份到 ASCII 路径（public/ 与 dist/ 需完整同步，漏拷图片会破图）后再构建。

构建细节与踩坑记录见 [PLAN-v1.0.3-新版解题页面适配.md](./PLAN-v1.0.3-新版解题页面适配.md)。

## 常见问题

<details>
<summary><b>按 Alt + C 没有反应？</b></summary>

确认程序在托盘运行中；确认游戏为无边框窗口化（非独占全屏），独占全屏下置顶窗口不可见。
</details>

<details>
<summary><b>符文或反馈色识别不准？</b></summary>

结果窗口会展示本次识别到的 4 个符文与 4 种颜色，逐项点开即可改为正确的符文 / 颜色，改完自动重算推荐；也可「撤回本次」后重试。若整体都不准，可在结果窗口用框选按钮手动框选符文面板区域再识别。
</details>

<details>
<summary><b>开滤镜后识别不准？</b></summary>

反馈色按边框相对色序判定，已适配英伟达动态亮丽 / 游戏内增亮等亮度类滤镜；若使用强色调滤镜（如夜视模式）仍异常，可提交 issue 附全屏截图。
</details>

<details>
<summary><b>4K / 高分辨率下识别失败或界面过小提示？</b></summary>

识别会按实际字高自适应缩放；若仍失败，用结果窗口的框选按钮手动框选完整符文面板（含 4 个符文与其边框），选区过小会自动放大后再识别；游戏内界面缩放调大也可显著提升识别率。
</details>
