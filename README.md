# GOC 解题妙妙小工具

GMOD-RXSEND-MIO服务器5K模式中，为解决GOC学术造假问题的由中分神秘博士设计的解题工具。识别 GOC 奇术终端新版解题页面的三卡片密文，按每张卡片的「前移/后移 N 位」标签自动解密，结果置顶展示并一键复制。

当前版本 **v1.0.3**（新版解题页面适配）。

## 工作流程

`Alt + C` 全屏截图 → Rust 像素预筛定位三张密文卡片 → Windows.Media.Ocr（系统内置，离线）识别「前移/后移 N 位」标签与密文 → 按标签语义解密（后移 N 位 → 每字母 -N；前移 N 位 → 每字母 +N）→ 置顶不抢焦点的结果窗口展示三行「密文 → 答案」映射。

- **颜色判定采用相对色序**（通道差 + 跨色相对序），不依赖绝对 RGB 阈值，适配英伟达动态亮丽/游戏内增亮等滤镜引起的颜色漂移
- **灰度归一化预处理**（底色→白、文字→黑、保留抗锯齿），提升 OCR 识别率
- **自学习**：结果窗口内可修正答案，修正写入本地 JSON，后续识别优先参考历史

## 结果窗口

- 始终置顶 + 不抢焦点（WS_EX_NOACTIVATE），不打断游戏按键
- 显示三行「密文原文 → 解密答案」，默认复制第一个答案
- 点击任意答案行即复制该答案并重置 10 秒倒计时，到期自动隐藏
- 拖动窗口期间倒计时自动冻结

## 使用方法

- 快捷键：`Alt + C` 自动全屏截图识别
- 托盘菜单：查看日志等辅助功能
- 系统要求：Windows 10 及以上；识别依赖系统内置中文 OCR 语言包（zh-CN）
